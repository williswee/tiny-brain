# My workspace

## Goals and success

Record the user's priorities and what a useful result would look like, when known.
Do not invent targets, metrics, or deadlines. Unknown details can stay unknown.

## Current work and first task

Describe the chosen task, relevant background, and the input the user has available.

## Constraints and boundaries

Record limits the user states: time, resources, tools, requirements, or things to
avoid. Do not assume that any particular constraint applies.

## Working preferences

Record stated preferences for tone, detail, format, and collaboration. Use the
default response style when no preference is supplied.

## Saving and current work

Record the user's selected saving choice in plain language. The active workflow
owns the task scope and any authorized checkpoint path; link to it rather than
copying the result into this profile. Distinguish setup only from setup plus that
task's actual result and progress. Do not infer ongoing saving from a request to
save one result. Chat-only setup is not written to this file.

## Context notes

Include only relevant facts the user has approved for saving, with the date
confirmed. Goals, project details, preferences, and people are optional topics,
not required fields. Invite one when it will help current work, accept skip, and
show new content before saving it unless that exact change is already authorized.
For people, keep only the role or relationship detail needed for the task. Do not
infer personal traits, turn one task choice into a general preference, or copy a
sample profile. Keep secrets and full transcripts out of this file. Check a
possibly stale fact with the user before relying on it.

## Additional context files

Initially there are none. When useful detail warrants its own file or the user
requests one, propose the content in plain language and obtain consent before
persisting it. Link to its approved file here and remove duplicated detail from
this profile. Use the optional paths in `README.md` without asking the user to
learn them. Omit unused optional headings from the saved profile rather than
turning them into a questionnaire or creating empty files.
